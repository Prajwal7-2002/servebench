## Reporting a Vulnerability

If you discover a security vulnerability in `servebench`, please report it responsibly.

* **Do not open a public issue.**
* Please report the issue privately through [GitHub's Private Vulnerability Reporting](https://github.com/Prajwal7-2002/servebench/security/advisories/new) or by emailing Prajwal Pujari at `prajwalpujari16@gmail.com`.

Include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Potential impact.

You will receive an acknowledgment within 48 hours, followed by an update on the fix and coordinated disclosure.
